SOC detection engineering home lab

Security
  • A Wazuh and Sysmon lab where each controlled attack scenario gets a custom detection rule, rule testing, and an incident-style report with evidence, a verdict and detection limitations. Scenarios include SSH password guessing, PowerShell execution, persistence and service creation.
  • Featured investigation: a scheduled task that launches PowerShell. I correlated the task definition (Event 4698), Task Scheduler execution logs and Sysmon process and file events through the ProcessGuid, compared baseline, elevated and hidden variants, and concluded benign while stating what the evidence does not prove.
  • Findings are mapped to MITRE ATT&CK as behavioral context, not as proof of malicious intent.

PhishCheck — phishing triage assistant

Security + software
  • A course prototype for Practical Generative AI, built extensively with an AI coding assistant. Flask, PostgreSQL, and the HTML/JavaScript frontend were course requirements; AI proposed much of the remaining implementation. It uses sample procedures written for the project, not official college policy.
  • Designed for a student with a suspicious message: paste a message, link or email headers, describe what happened, and get the matching steps for that situation.
  • A router chooses per message between inspecting it with tools, retrieving a documented procedure, or answering directly, and shows its reasoning.
  • Two rule-based analyzers check pasted links and email headers for lookalike domains, display-name spoofing and failed authentication. They only read the text and never visit a URL.
  • The assistant is instructed to keep what the user reported, what the tools found, and what remains uncertain separate, and to avoid declaring a message safe.
